## 🚀 Getting Started

Follow these steps to run the portfolio locally:

### 1. Prerequisites

Ensure you have **Node.js** (v18.0.0 or higher) and **npm** installed:
```bash
node -v
npm -v
```

### 2. Clone the Repository

```bash
git clone https://github.com/Aditya1791/aditya-swain-_-developer-portfolio.git
cd aditya-swain-_-developer-portfolio
```

### 3. Install Dependencies

```bash
npm install --legacy-peer-deps
```

### 4. Launch Development Server

```bash
npm run dev
```

The application will run locally at:
```
  ➜  Local:   http://localhost:3000/
  ➜  Network: http://<your-lan-ip>:3000/
```

### 5. Typecheck & Build

```bash
# Typecheck TypeScript code
npm run lint

# Build static production bundle into dist/
npm run build
```
